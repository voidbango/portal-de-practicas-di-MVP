# Portal de Prácticas DI - UTFSM (MVP)

Prototipo de Producto Mínimo Viable (MVP) interactivo desarrollado en React para el rediseño y modernización del Portal de Prácticas del Departamento de Informática (UTFSM).

## Metas de Usuario Implementadas

1. **Búsqueda y Postulación a Ofertas:** Exploración de vacantes con filtros avanzados (modalidad, remuneración, stack técnico), desglose de afinidad/matching y confirmación de postulación.
2. **Inscripción de Práctica:** Formulario guiado de formalización de práctica según normativa reglamentaria, registro de datos de empresa y supervisor.
3. **Seguimiento, Bitácora e Informe Final:** Registro periódico de bitácora semanal, monitoreo de horas completadas y entrega de informe final / evaluación de supervisor.
